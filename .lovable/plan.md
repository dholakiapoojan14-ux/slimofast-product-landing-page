# Slimofast product page

## What to build
- Replace the placeholder home page with a mobile-first Slimofast product page matching the supplied PDF and checkout screenshot.
- Add selectable weight goals that update the offer details, an open-and-close FAQ, a validated order form, and a complete subscription form that opens WhatsApp.
- Add the clean, centered thank-you page and the fixed Order Now button that scrolls to and focuses the order form.

## Technical approach
- Keep the existing TanStack Start app framework and implement the two pages as routes.
- Use the supplied PDF images, semantic design tokens in the shared stylesheet, and Zod client-side validation. Do not add APIs, persistence, or payment processing.
- Clearly mark the WhatsApp destination number as a replaceable placeholder; explain that WhatsApp subscription links need its confirmed number.
